# Policy documentation suite (redacted public sources)

LaTeX sources for standard-operating-procedure manuals and FAQs. Written for a municipal extra-duty / per-session employment process.

Operational mailboxes, phone numbers, and internal site names are replaced with placeholders in this public copy. Compiled PDFs of the live manuals are not published here.

| Source | Purpose |
|---|---|
| [`SOPM-SchoolBasedPS.tex`](SOPM-SchoolBasedPS.tex) | School-level workflow structure |
| [`SOPM-CentralBasedPS.tex`](SOPM-CentralBasedPS.tex) | Central-office workflow structure |
| [`PrincipalPerSessionFAQ.tex`](PrincipalPerSessionFAQ.tex) | Principal-facing FAQ structure |
| [`PerSessionFAQ.tex`](PerSessionFAQ.tex) | Staff-facing FAQ structure |

**Stack:** XeLaTeX, `titlesec`, `fancyhdr`, `hyperref`

Contacts in these files (`staff@example.org`, `555-0100`) are placeholders. Do not treat them as live routing.
