# Policy documentation suite (generic public samples)

LaTeX sources for standard-operating-procedure manuals and FAQs. Written as sample materials for a municipal extra-duty / temporary assignment employment process.

All operational details, internal system names, regulations, and live contacts have been replaced with placeholders or lorem ipsum. Compiled PDFs are not published.

| Source | Purpose |
|---|---|
| [`SOPM-SchoolBased.tex`](SOPM-SchoolBasedPS.tex) | Site-level workflow structure (genericized) |
| [`SOPM-CentralBased.tex`](SOPM-CentralBasedPS.tex) | Central-office workflow structure (genericized) |
| [`PrincipalAssignmentFAQ.tex`](PrincipalPerSessionFAQ.tex) | Supervisor-facing FAQ structure (genericized) |
| [`AssignmentFAQ.tex`](PerSessionFAQ.tex) | Staff-facing FAQ structure (genericized) |

**Stack:** XeLaTeX, `titlesec`, `fancyhdr`, `hyperref`, `tocloft`

Placeholder contacts (`staff@example.org`, `555-0100`) are not live. Do not treat any content as operational policy.
